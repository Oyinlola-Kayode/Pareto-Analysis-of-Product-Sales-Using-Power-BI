# Pareto-Analysis-of-Product-Sales-Using-Power-BI
This project applies the Pareto Principle (80/20 rule) to identify top-performing products that drive the majority of sales. Out of 35 products, 15 account for 80% of total revenue (~$14.4M). The analysis guides data-driven decisions in inventory management, marketing, and product strategy through an interactive Power BI dashboard.
